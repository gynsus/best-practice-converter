Конвертер прайс-листов

Автоматическая служба, которая ежедневно превращает прайс-листы поставщиков в файлы единого формата для загрузки на сайт. Работает без участия человека.

Поставщикипрайс-листы Excel и XML — у каждого свой формат
→
Папка input\\dev.best-practice.ru\input
→
Конвертережедневно в 22:00, около 2 минут
→
Папка outputCSV единого формата + сигнал done.txt
→
Сайтмодуль загрузки забирает данные

Что делает конвертер

Каждый поставщик присылает прайс в собственном виде: разные колонки, листы, единицы измерения, обозначения валют и наличия. Конвертер приводит всё к единой таблице из 21 колонки (артикул, наименование, группа товаров, цена, валюта, количество, габариты, вес, объём, гарантия, состояние товара и др.). При этом:

  • валюты приводятся к стандарту (RUR, руб., ₽ → RUB; $ → USD; € → EUR);
  • габариты — к сантиметрам, вес — к килограммам, объём — к кубометрам (если поставщик не указал объём, он вычисляется из габаритов);
  • числа очищаются от разнобоя форматов (разделители, «научная запись»);
  • состояние товара нормализуется: Стандарт, Распродажа, Некондиция, Дефект упаковки, Из ремонта и т.п. — по справочникам каждого поставщика;
  • тексты очищаются от служебных символов, которые ломают загрузку.

Каждая строка результата получает сквозной номер, а обработанные исходники аккуратно складываются в архив по датам — всегда можно поднять историю и сверить любую цифру с оригиналом поставщика.

Надёжность

  • Ошибка одного поставщика не мешает остальным. Если поставщик изменил структуру прайса, его файл помечается ошибкой с точным описанием (например, «не найдена колонка “Цена”»), остальные обрабатываются как обычно. Неверные данные «со сдвигом колонок» в результат попасть не могут.
  • Сигнал готовности. Файл done.txt создаётся только после завершения всей обработки — сайт никогда не заберёт данные «наполовину».
  • Защита от наложения запусков и повторных прогонов в один день.
  • Полный архив. Оригиналы прайсов, журнал работы и отчёт каждого прогона хранятся в папке архива по датам.

Обслуживание

  • Расписание: ежедневно в 22:00 (задача «PriceConverter» в Планировщике Windows; время можно изменить).
  • Новый поставщик или смена имени файла — правка одного файла настроек settings.yaml, конвертер трогать не нужно.
  • Если поставщик временно «сломал» прайс — его можно отключить одной строкой в настройках (enabled: false), остальные продолжат работать.
  • Проверка без обработки: команда main.py --check показывает доступность папок и какой файл каким правилом будет подхвачен.
Технически: служба написана на Python 3.12, работает на Windows-сервере, папки обмена — сетевые (\\dev.best-practice.ru). Установлена в C:\Convert\best-practice-converter; обновление — одной командой, настройки при обновлении сохраняются.
